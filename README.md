# Himu Sex Boys Club — HK Style Taiwanese Mahjong

A static, mobile-first scorekeeper for **HK Style Taiwanese Mahjong** (港式台牌). No server and no build step: scores stay in the browser via LocalStorage.

## Run

Open `index.html` in a browser, or serve the folder with any static file server.

or check https://mj.mayu54.com

## Features

- Four-player table with seat icons, dealer, consecutive dealer (連莊), and round wind
- Record **zimo** (自摸), **ron** (食糊), including **multiple ron** on one discard (up to three winners)
- **La** (拉數) with 1.5× stacking, 踢半, and surrender every 3 / 6 / 9 counts
- Draw (流局) with optional dealer stay
- **Special bonuses / penalties** (特別賞罰): pay or receive, all others or chosen players, priced in 底 (1 底 = 5 番)
- Score history as a four-column timeline
- Stats and titles after one full cycle of East / South / West / North
- Mid-game add or swap players; undo last hand

Default table: **2.5 底 / 0.5 per 台**. Base fan is always 5.
