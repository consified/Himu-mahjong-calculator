幫助

這是一個專為 Himu Mahjong（港式台牌）開發的麻雀計數器。

此工具所收集的資料將會在用戶手機本地內儲存，並不會上載到任何伺服器。運作方式請參考 GitHub 專案。

主要功能

  • Mark 底總數、圈數、拉踢數、綜合數據等等
  • 自摸／食糊入數可以打開計數機逐個數番
  • 生成食糊成就的圖片，供用戶以社交媒體分享給朋友
  • 客製化玩家名稱以及 Icon

實裝功能不限於以上清單，其他功能將會陸續開發。

如有發現任何 Bug 和任何算法錯誤，或你想提交意見，請於專案內 Post issue；喜歡此專案的話不妨可以點個星星。
